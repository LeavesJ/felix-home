### 2026-10-13: gate friction step 1, one suite pass per landing (PR A #432, A3)

**Engines 0.49.284 (#432, landed and deployed) and 0.49.285 (A3, this branch).**
Row 0 of the queue, from the design the founder approved on 2026-10-12:
docs/2026-10-12-gate-friction-design.md, with contracts A, A2 and A3 beside it.
The founder's target is about five minutes from an engine change being built to
landable on a quiet machine. Today an engine change pays the whole suite three
times: the record, red, and the gate.

**What landed in #432.**
- `tests/run --record-assertions` starts red at its own start and waits for red
  at the end, then judges again the record it wrote (`_rt_judge`, part 1010).
- A run that passes leaves a suite receipt (tests/receipt.sh) in the git
  directory. It names the tree id, the environment and origin/main, and holds
  for 12 hours.
- `tests/run --reuse` answers from that receipt and says so, and gate.sh reports
  `tests reused`.
- Rule C9 in `felix merge`: a receipt reporting `tests:reused` merges only on a
  completed, successful gate workflow run on the exact head.

**What A3 adds.** Rule C10: a suite run's receipt stands across exactly one
commit whose content is what the run left. HEAD must have one parent, and the
id computed as if HEAD were that parent must equal the receipt's. The parent
must not already be in origin/main, and it must have exactly one merge-base
with origin/main (review finding C10-1: after a criss-cross, git's choice
between two equal merge-bases differed between the parent and HEAD). Without
C10, record, commit, gate never reused, because the tree id hashes HEAD's sha.

**Found on the way.**
- `felix gate` in a worktree runs the home checkout's projects/felix/gate.sh,
  not the branch's, so a gate.sh change is proved by its parts (1230) and
  binds only once it is in the home.
- #431 landed during #432's gate and staled its record (`_rtn4`). Main was
  merged in, 0.49.284 taken, and the record run again.
- #431 took parts 1100 to 1120. The gate-friction parts are 1200 to 1260.
